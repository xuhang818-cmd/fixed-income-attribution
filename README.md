## Risk metrics

- **DTS (Duration Times Spread)** — credit risk measure, rolling and point-in-time
- **DV01** — price sensitivity to 1bp rate move per $1M notional, split by KRD node
- **Spread VaR / CVaR** — 10-day 95% historical simulation
- **Drawdown** — peak-to-trough return series for LQD, HYG, and portfolio
- **Risk contribution split** — DTS-weighted IG vs HY contribution, updates with weight sliders
